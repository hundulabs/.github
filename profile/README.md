# Hundu Labs

Hundu Labs is the GitHub organization for Hundu, an Infrastructure as Code project.

Hundu is intended to provide a declarative language and tooling for defining, validating, planning, and managing infrastructure changes.

Its scope includes a compiler, an extensible provider system, infrastructure state management, and an execution engine with an emphasis on predictable behavior and recovery from failures.

The core tooling is designed around an open-source model and independent operation. Hundu Cloud is the proposed managed component for teams, covering shared workflows, change reviews, access control, and infrastructure coordination.
